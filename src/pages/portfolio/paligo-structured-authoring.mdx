# Structured authoring in Paligo

:::important

Proprietary content is genericized and Paligo's internal attributes are removed in XML code blocks for readability.

:::

This XML comes from a Paligo library of ~750 topics and reusable components behind ~20 guides.

The sample topic below appears in two guides with different audiences. Six levels of structured reuse are in place:

- Topics placed in more than one spot
- Topics inside other topics
- Reusable step sets
- Reusable notes
- Shared sentences and paragraphs
- Variables

Certain content is tagged with `audience` attributes so each published guide includes only what its readers need.
