# Zendesk and Paligo help site

\{@include: /src/includes/disclaimer.md\}

I built this help site from scratch using a Paligo XML CCMS > Zendesk pipeline.

## Information architecture

The main complexity of building the site was the fact that two software applications had some parity but not completely. For example, two **How to audit rosters** articles existed - one for the first software app and one for the second - but they contained different steps. The first rung of the information architecture was clear entry points into content specific to the app the user is using.
