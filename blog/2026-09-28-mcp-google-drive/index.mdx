**What it is**: This MCP lets me perform one action that the company's MCP did not: manage content as Markdown.

**Why I built it**: Formatting a Google Doc with a Google Drive connection in AI tool is notoriously unpredictable. Applied styles can be offset by a character or two, bullets can misalign, and formatting can disappear. This custom MCP allows the content to be extracted from the Google Doc as Markdown using the Google Docs API's `text/markdown` export MIME type, formats the content straightforwardly Markdown, and converts it into a native Google Doc format.
