# How I built a REST API so I could document it

Claude and I built a REST API -- because who doesn't need a programmatic way to get facts about Norway? (Norway is dear to my heart because I served a mission there for the Church of Jesus Christ of Latter-day Saints.) I've built developer portals, edited content in OpenAPI and Swagger YAML files, submitted bugs when samples don't work, and used a lot of REST API documentation, but I've never had the chance to fully document one and add working samples.
