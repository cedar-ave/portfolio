Have you ever worked with a CMS or CCMS that required *lots* of repetitive clicking through UIs to get things done? If the tool has a REST API, you can trade those clicks for natural language prompts by building a simple API wrapper MCP and an AI agent skill. And I don't mean by coding it yourself.

{/* truncate */}

I once needed to add labels to hundreds of articles in a Zendesk site. Labels are great because they optimize search results and AI-generated quick answers. But I was looking at hours of tedious clicks and entering terms.

The Zendesk REST API offered a way out. It offers these endpoints:

- `articles`: List all articles and see an article's label
- `labels`: Add a label to an article
