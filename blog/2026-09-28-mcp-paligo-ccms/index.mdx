This is part of a series about custom [MCP](https://modelcontextprotocol.io/) servers I've built to connect the systems I work in, so I can generate content from the information they hold, set up workflows that cover multiple tools, and eliminate manual, repetitive work that would otherwise only be possible through the application UI.

## What it is

This MCP server performs actions like creating, updating, and deleting articles; creating publications and productions; uploading and inserting images; and managing taxonomies and variables. It is a wrapper around the [Paligo API](https://docs.paligo.net/en/paligo-rest-api.html). 

## Why I built it
It's tedious and time consuming to work with Paligo content by clicking around the Paligo UI performing one action at a time. AI agent skills using this MCP server can perform multiple actions at a time - even a full publishing workflow - from transforming a Google doc into XML according to the Paligo XML spec, uploading it to a new document in Paligo, adding it to a guide's table of contents, and triggering the publishing pipeline.

See [Paligo Pal](/portfolio/ai-agent-skills/#paligo-pal) for a sample of an AI agent skill that uses the Paligo MCP server.
