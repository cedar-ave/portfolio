# Release recap

This type of descriptive, user-friendly version of release notes was published after each release. The goal was to help users understand what changed without diluting the messaging with too many technical details.

I used Claude AI agent skills to generate and validate the content, then pushed it through a loop of human reviewers. The skill analyzed relevant content from product roadmaps, enablement briefs, Jira tickets, PRDs, demo  transcripts, etc., to create the first draft of the recap.

In the published version, each release note was followed by links to the accompanying help articles that tell users more about each change and what steps they should take to bring it into their workflow.
