# Blog feeds and authoring checks

<QuickReference>

| To do this | Change this |
| --- | --- |
| Turn RSS/Atom feeds off | Delete `feedOptions` from the `blog` block in `docusaurus.config.js` |
| Generate only one feed type | Set `feedOptions.type` to `['rss']` or `['atom']` |
| Show raw XML when the feed URL is opened in a browser | Set `feedOptions.xslt` to `false` |
| Make an authoring check fail the build | Set `onInlineTags`, `onInlineAuthors` or `onUntruncatedBlogPosts` to `'throw'` |
| Silence an authoring check | Set it to `'ignore'` |
| Change how many posts show per blog list page | Edit `POSTS_PER_PAGE` in `src/theme/BlogListPage/index.js` (currently `10`) |

**Don't change:** `blogSidebarCount: 'ALL'` (needed by [blog post series](blog-post-series)) or `postsPerPage: 'ALL'` (needed by [blog index list filtering](blog-index-list-filtering)).

</QuickReference>

All settings below live in the `blog` block of the classic preset in `docusaurus.config.js`:

```js title="docusaurus.config.js"
presets: [['classic', {
  blog: {
    blogSidebarCount: 'ALL',      // don't change
    postsPerPage: 'ALL',          // don't change
    feedOptions: {
      type: ['rss', 'atom'],
      xslt: true,
    },
    onInlineTags: 'warn',
    onInlineAuthors: 'warn',
    onUntruncatedBlogPosts: 'warn',
  },
}]],
```

## Feeds

| Setting | Current value | Options |
| --- | --- | --- |
| `feedOptions` | present | Delete the whole key to stop generating feeds |
| `feedOptions.type` | `['rss', 'atom']` | `['rss']`, `['atom']`, or both |
| `feedOptions.xslt` | `true` | `false` to serve plain XML in the browser |

Feed URLs: `/blog/rss.xml` and `/blog/atom.xml`.

## Authoring checks

| Setting | Current value | Triggers when a post… |
| --- | --- | --- |
| `onInlineTags` | `'warn'` | defines a tag inline in frontmatter instead of using one from `blog/tags.yml` |
| `onInlineAuthors` | `'warn'` | defines an author inline instead of using one from `blog/authors.yml` |
| `onUntruncatedBlogPosts` | `'warn'` | has no `<!-- truncate -->` marker |

Set each to `'warn'`, `'throw'` (fail the build) or `'ignore'`.

To clear a warning in a post:

- **Inline tag:** add the tag to `blog/tags.yml`, then reference it by key in the post's `tags:` list.
- **Inline author:** add the author to `blog/authors.yml`, then reference it by key in the post's `authors:` list.
- **Untruncated post:** add `<!-- truncate -->` where the excerpt should end.

## Posts per page

Edit `POSTS_PER_PAGE` in `src/theme/BlogListPage/index.js`. Leave `postsPerPage: 'ALL'` in `docusaurus.config.js` as is.

## Background

### Feeds

The classic template ships with no `feedOptions` at all, so no feed is generated by default. The current config produces both `/blog/rss.xml` and `/blog/atom.xml`. `xslt: true` attaches a stylesheet to the generated XML purely for readability if someone opens the feed URL directly in a browser instead of a feed reader — it has no effect on how feed readers consume it.

### Authoring checks

None of the three authoring options are set in the template (they default to off). With `'warn'` they only print console warnings during `npm start` / `npm run build` — none of them fail the build.

- **`onInlineTags`** — flags a post that defines a tag inline in frontmatter (e.g. `tags: [{label: "Foo", permalink: "/foo"}]`) instead of referencing a tag declared once in `blog/tags.yml`.
- **`onInlineAuthors`** — flags a post that defines an author inline instead of referencing one declared in `blog/authors.yml`.
- **`onUntruncatedBlogPosts`** — flags a post with no `<!-- truncate -->` marker, meaning the full post body renders on the blog list page instead of an excerpt.

### Sidebar post count

The blog plugin defaults to showing only the 5 most recent posts in the sidebar. `blogSidebarCount: 'ALL'` overrides this to show every post, which is a hard requirement for the [blog post series](blog-post-series) grouping — that feature reads from the full sidebar item list to sort posts into series buckets, so capping it at 5 would silently drop older posts from both the year list and their series. See that page for the full explanation.

### Posts per page

`postsPerPage: 'ALL'` is required by [blog index list filtering](blog-index-list-filtering). The actual per-page post count shown to visitors lives in `src/theme/BlogListPage/index.js` (`POSTS_PER_PAGE`), not in `docusaurus.config.js`.
