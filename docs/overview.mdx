# Overview

This section documents everything that has been customized beyond a stock Docusaurus install: custom components, deployment settings, and known issues. It is meant as a reference for future you, not for site visitors.

| Customization | Where to change it | Details |
| --- | --- | --- |
| Gallery component | `src/components/Gallery` | [Gallery](visuals/gallery) |
| Panel component (soft-bordered content block) | `src/components/Panel` | [Panel](visuals/panel) |
| Homepage features row | `src/components/HomepageFeatures/index.js` | [Homepage features](home-page/homepage-features) |
| Page diagrams (per-experience-page SVG figures) | `src/components/*Diagrams` folders | [Page diagrams](visuals/page-diagrams) |
| Release notes page mockups (text/content of each sample) | `src/components/*Mockup` folders used by the three `release-notes-*.mdx` pages | [Release notes page mockups](visuals/release-notes-mockups) |
| Deployment | `npm run deploy`, env vars `USE_SSH` / `GIT_USER` | [Deployment](build-deploy/deployment) |
| Known build issues | n/a | [Troubleshooting](troubleshooting/panic-occurred-at-runtime) |
| Navbar items | `docusaurus.config.js` | [Navbar](site-config/navbar) |
| Footer links and color | `docusaurus.config.js`, `src/css/custom.css` | [Footer](site-config/footer) |
| Title, tagline, favicon, social card, analytics | `docusaurus.config.js` | [Site metadata](site-config/site-metadata) |
| Homepage tagline lines and icons | `docusaurus.config.js`, `src/pages/index.module.css`, `static/img/home-page/` | [Hero tagline](home-page/hero-tagline) |
| Blog RSS/Atom feeds, authoring warnings | `docusaurus.config.js` | [Blog feeds and authoring checks](blog/blog-feeds-and-authoring) |
| Broken-link checking, future flags, "Edit this page" links | `docusaurus.config.js` | [Build flags and edit links](build-deploy/build-flags-and-edit-links) |
| Image sizing syntax + click-to-zoom | `plugins/remark-image-size.mjs`, `docusaurus-theme-zoom-image` | [Image handling](visuals/image-handling) |
| Blog card look, tag styling, swizzled blog components | `src/theme/BlogPostItem/*`, `src/theme/TagsListInline`, `src/theme/BlogTagsPostsPage` | [Blog post cards and tags](blog/blog-post-cards) |
| Global layout/spacing/table CSS not covered above | `src/css/custom.css` | [Global CSS overrides](site-config/global-css) |
| Blog post series grouping in the sidebar | `src/data/blogSeries.ts`, `src/theme/BlogSidebar/*` | [Blog post series](blog/blog-post-series) |
| Palette | `src/css/custom.css` | [Colors](styling/colors) |
| Per-page TOC built from panel captions instead of headings | `plugins/remark-panel-toc.mjs`, frontmatter `toc_source: panels` | [Panel-based table of contents](visuals/panel-toc) |
| Typeface | `docusaurus.config.js`, `src/css/custom.css` | [Fonts](styling/fonts) |
| `/samples` demo docs instance (sample product user guide, not in navbar) | `docusaurus.config.js`, `samples/`, `src/js/sidebars-samples.js` | [The /samples section](samples-section/overview) |
| `{@include: path}` content reuse across docs, blog, samples, and pages | `plugins/remark-includes.mjs` | [Content includes across sections](site-config/content-includes) |
| Site search (local index, no external service) | `docusaurus.config.js` | [Search](site-config/search) |
