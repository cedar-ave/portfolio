# Create a new app

1. Go to the Collect home page.
2. Click **New Application**.

## Give the app a name, description, and owner

| Field | What to enter | Example | Notes |
|---|---|---|---|
| Name | The name of your app | Property Claims | Two apps can't share the same name. |
| Description *(optional)* | A description of your app | Captures claim notes and inspection details for property claims | |
| Schema | Fills in automatically from the app name; you can change it | Group all property-line apps in a `PropertyLine` schema, and all underwriting apps in an `Underwriting` schema | By default, each app gets its own schema. If you enter a schema name that matches an existing one, the apps will share it, unless you type a name matching the app's own name. |
| Owner | The app's creator, owner, or contact person | Dana Ruiz | |

Fields that are required or contain invalid data are outlined in red; hover over the alert icon next to one for details.

3. Click **Save**. The app appears as a new tile on the home page.
4. [Assign permissions](./08-security-roles) so the right roles can use it.
