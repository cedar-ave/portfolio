# Glossary

## Data structure

| Component | What it is |
|---|---|
| Main table | The table with the app's main data |
| Subset table | A table with a subset of data connected to the Main table |
| Record | A row in the Main table or a subset table |
| Field | An individual piece of data with a label and a data type; a collection of fields makes up a record |

## Example

The Main table has a record for every claim. A **Claim Notes** subset table has a record for each note logged against a claim — each note record ties back to a particular claim.

To add a note, a user opens the claim's record and enters a new row in the **Claim Notes** subset.
