# Data-type definitions

Only valid records can be inserted or updated. The table below shows each data type's input control and valid format.

| Field data type | Input type | Valid format | Example |
|---|---|---|---|
| Text | Text box | Any text | Example text |
| Date/Time | Date/Time picker *(also accepts direct input)* | M/D/YYYY H:MM AM/PM | 7/12/2026 2:31 PM |
| Date | Date picker *(also accepts direct input)* | M/D/YYYY | 7/12/2026 |
| Time | Time picker *(also accepts direct input)* | H:MM AM/PM | 2:31 PM |
| Decimal | Text box | #.# | 3.14 |
| Integer | Text box | # | 7 |
| True/False | Check box | Checked or unchecked* | Checked |

\* Unchecked is the initial state of the field in a new record.
