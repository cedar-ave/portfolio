# Prerequisites

## Understand the Collect setup

Clearpath Collect is:

- A web-based application you use within a browser
- Dependent on a database and an application server

## Install the Clearpath platform

Complete the steps in:

- The Clearpath Pre-Install Checklist
- The Clearpath Install Guide

## Install Clearpath Collect

Complete the steps in the Clearpath Collect Install Guide.

## Complete the data migration checklist

- Existing metadata converted to Clearpath metadata
- Destination tables created from metadata
- Existing data transferred to new destination tables
- For upgrades only: a one-time run of the Collect Migration Tool to bring over apps from a previous version — see the Clearpath Collect Migration Tool Guide

## Supported browsers

Collect is supported on Chrome, Edge, Firefox, and Safari. Chrome is recommended.

## Clearpath Collect documentation

- Clearpath Collect Install Guide
- Clearpath Collect Migration Tool Guide
- Clearpath Collect User Guide
- Clearpath Collect API Reference

The API Reference is embedded directly inside Collect and stays up to date with the version you're running. From anywhere within Collect, click your username, then **About**, then **API Reference**.
