### Build pipelines

There is one pipeline per Classic edition version. A script task concatenates and publishes the results of the open and closed bugs queries to a single Clearpath Community page.

See [Known issues setup](./37-known-issues-setup#build-pipelines) for pipeline naming conventions.

#### YAML build file variables

See [Community site pages setup](./43-community-site-pages-setup#base-64-encoded-api-token) for steps to get a token for the `restUserToken` pipeline variable and get Clearpath Community wiki and wiki page variables.

#### Local scripts assemble the report

The pipeline executes scripts in the **scripts/known-issues-combined** subdirectory in the release-notes repo to output a document assembled from the two queries:

- md-to-html.ps1: Transforms Markdown exported during the Release Notes extension task to HTML
- prettify-css.ps1: Applies CSS styles supported by Clearpath Community
- concat-final-output.ps1: Fix any formatting problems and concatenate reports of open and closed bugs

### Refresh

The report of critical and high bugs is refreshed [the same way as known issues](./40-refresh-known-issues-and-critical-and-high-bugs).
