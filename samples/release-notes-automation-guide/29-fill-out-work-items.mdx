# Fill out work items

Release notes, known issues, and critical and high bugs reports are generated from Azure DevOps work items based on [Work item logic](./27-work-item-logic).

## Mark required fields

Mark the following fields on the **RN** tab of Azure DevOps Feature, Product Backlog Item, and Bug work items:

### Mandatory field

- **Publish**: **Yes** or **No**

If two or more work items describe the same functionality, only one should translate to a release note. Select **Yes** on one of the work items and select **Yes, but covered elsewhere** on the others.

### If Publish is Yes

- **Product(s) affected**
- **Version(s) affected**
- **Release Note**: See [Release notes writing guidance](./30-release-notes-writing-guidance)
