# Fields, roster objects, and sub-objects

## Fields

A field in Clearpath corresponds to a column in a roster. For example, a **First Name** field becomes a **First Name** column with a row for each producer's first name.

## Roster objects

A roster object contains one or more fields. For example, an object named **Contact** contains the fields **First Name**, **Last Name**, **NPN**, and **Birthdate**. When [configured in a template](./configure-a-template-s-layout), this is how the data outputs:

| First Name | Last Name | NPN       | Birthdate  |
|------------|-----------|-----------|------------|
| Patrick    | Hopkins   | 123456789 | 01/01/1988 |

## Sub-objects in roster objects

A sub-object is an object related to the roster object via a lookup field.

For example, the **License** object has a **Contact** field that you can use as a lookup field to reference the producer when you [configure a template's layout](./configure-a-template-s-layout). If the producer holds multiple licenses, the selected columns repeat themselves:

| License 1 : License Type | License 1 : License Number | License 1 : License State | License 1 : License Expiration Date | License 2 : License Type | License 2 : License Number | License 2 : License State | License 2 : License Expiration Date |
|---------------------------|-----------------------------|-----------------------------|----------------------------------------|----------------------------|-----------------------------|-----------------------------|----------------------------------------|
| Property & Casualty       | 123456                      | CA                           | 04/15/2025                              | Life, Accident & Health    | 654321                      | NV                           | 03/27/2025                              |

If fields and sub-objects are used together in a template, both the fields and sub-objects are included as columns:

| First Name | Last Name | NPN       | Birthdate  | License 1 : License Type | License 1 : License Number | License 1 : License State | License 1 : License Expiration Date | License 2 : License Type | License 2 : License Number | License 2 : License State | License 2 : License Expiration Date |
|------------|-----------|-----------|------------|---------------------------|-----------------------------|-----------------------------|----------------------------------------|----------------------------|-----------------------------|-----------------------------|----------------------------------------|
| Patrick    | Hopkins   | 123456789 | 01/01/1988 | Property & Casualty       | 123456                      | CA                           | 04/15/2025                              | Life, Accident & Health    | 654321                      | NV                           | 03/27/2025                              |
