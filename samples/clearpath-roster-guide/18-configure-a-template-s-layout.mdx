# Configure a template's layout

First, [create a template](./10-create-a-template).

If you just [created a template](./10-create-a-template), clicking **Continue** as the final step takes you to the **Roster Templates** page.

If you're returning to a template you created previously, complete the following steps to get to the **Roster Templates** page.

1. Click the menu icon (<FAIcon icon="grip" />) at top left.

2. Click **View All**.

3. Click **Roster Template Setup**.

:::note

You'll use fields, roster objects, and sub-objects to design a template's layout. See [Fields, roster objects, and sub-objects](./19-fields-roster-objects-and-sub-objects) for details.

:::

In the **Available Fields** panel of the **Roster Templates** page, drag fields and objects into the box on the **Outline** tab of the center panel (also called **Templates Columns**) that you want to appear as columns in the roster template. Use the search field above the list of available fields and objects to narrow the list.

An icon next to each field or object in the panel shows what kind of data it contains.

| Field type icon                                                                                | What kind of field it is |
|------------------------------------------------------------------------------------------------|--------------------------|
| <FAIcon icon="font" />        | Text                     |
| <FAIcon icon="check" />            | Boolean; true/false      |
| <FAIcon icon="list" />         | Picklist                 |
| <FAIcon icon="hashtag" />           | Number                   |
| <FAIcon icon="calendar" />            | Date                     |
| <FAIcon icon="cube" /> | Object                   |

## Use objects and sub-objects in a template's layout

:::note

Learn more about [roster objects and sub-objects](./19-fields-roster-objects-and-sub-objects).

:::

In the **Available Fields** list, an object is represented with an object icon (<FAIcon icon="cube" />).

To include an object in a template's layout:

1. Drag an object into the box on the **Outline** tab of the center panel (also called **Templates Columns**).

2. Click the pencil icon (<FAIcon icon="pen" />) on the left side of an object's name.

3. Drag fields from the **Available** column into the **Selected** box.

4. Click **Save**.

5. Click **Save** at top right.

:::warning

If you include a sub-object in a template but don't select any fields to be included, you'll run into errors when you export the roster.

:::

You can also [remove or rename](./21-manage-fields-and-objects) a field or object.

Next, [create filters](./23-create-filters) or skip that step and [activate the template](./24-manage-templates).
