# Create a template

## Prepare to create a template

Following are some things to know about configuring a template.

- There is no limit for the number of templates you can create.

- Templates are shared at the organizational level, and all approved users can access all templates.

## Create a template

1. Click the menu icon (<FAIcon icon="grip" />) at top left.

2. In the search field, enter **Roster Template Setup**. When it shows in the list of results, select **Roster Template Setup**.

3. Next to **Clearpath Roster Templates**, click **Add New Roster Template**.

4. Enter a name for the template. Users will see this name when generating a roster. As a best practice, enter the name of the carrier the template is for.

5. Enter a description for the template.

## Clone a template

1. Click the menu icon (<FAIcon icon="grip" />) at top left.

2. In the search field, enter **Roster Template Setup**. When it shows in the list of results, select **Roster Template Setup**.

3. In the **Clearpath Roster Templates** table:

   1. Locate the name of a template.

   2. Click the down icon (<FAIcon icon="caret-down" />) at the end of its row.

   3. Select **Clone**.

4. Select one of the following options:

   1. Click **Full Clone** to clone the template name, description, object configuration, and columns.

   2. Click **Detail Clone** to clone the template name, description, and object configuration.

## Choose objects to store carriers and producers

Define an object schema between carrier and producer objects.

Fill out the following fields:

| Field           | What to select                                                                                                                                                                 |
|-----------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Carrier Object    | Search for an object to store carriers in. Usually, users select the **Account** object.                                                                                         |
| Producer Object | Search for an object to store producers. The object will have basic information like name and demographic data. Usually, users select the **Contact** or **Producer** objects. |
