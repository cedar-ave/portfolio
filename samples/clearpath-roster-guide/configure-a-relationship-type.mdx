# Configure a relationship type

## Configure a related record relationship type

First, [choose a relationship type](./choose-a-relationship-type).

The following fields are visible if you selected **Related Record** in the **Select Relationship Type** field.

Fill out the following field:

| Field | What to select |
|---|---|
| **Select Field for Reference** | This is the field on the roster object that identifies the carrier. Select a field to link the items on. Usually, this is the carrier object's ID or account ID. |

Click **Continue**.

Next, [design a template's layout](./configure-a-template-s-layout).

## Configure a junction object relationship type

First, [choose a relationship type](./choose-a-relationship-type).

The following fields are visible if you selected **Junction Object** in the **Select Relationship Type** field.

Fill out the following fields:

| Field | What to select |
|---|---|
| **Select Junction Object** | The **Select Junction Object** dropdown is shown if you selected **Junction Object** as the relationship type. Select the object that relates the producer to the carrier object. Usually, this is the **Producer Appointment** object. |
| **Select Reference to Carrier Object** | Select a field that references the carrier object. This is the field that identifies the carrier on the junction object. Usually, this is the **Account** object. |
| **Select Reference to Roster Object** | Select the field that relates the junction object to the producer. Usually, this is the **Contact** object. |

Click **Continue**.

Next, [design a template's layout](./configure-a-template-s-layout).
