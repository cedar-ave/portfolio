# Remove a field or object

## Remove a field or object

1.  Click the close icon (<FAIcon icon="xmark" />) next to a field's name in the box on the **Outline** tab of the center panel (also called **Templates Columns**).

2.  See the change reflected in the **Preview** panel.

## Remove a field in an object

If an object contains fields, the object name in the box on the **Outline** tab of the center panel (also called **Templates Columns**) will have a number next to it, like **E&O Insurance - 6**. This means there are six fields in the **E&O Insurance** object.

1.  Click the pencil icon (<FAIcon icon="pen" />) on the left side of an object's name in the box on the **Outline** tab of the center panel (also called **Templates Columns**).

2.  In the **Selected** box, click the pencil icon (<FAIcon icon="pen" />) on the left side of a field's name.

3.  Click the close icon (<FAIcon icon="xmark" />) next to a field's name in the **Selected** box and click **Save**.

4.  Click **Save**.

5.  See the change reflected in the **Preview** panel.
