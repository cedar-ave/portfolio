# Create a template

:::note

You can also [clone one of your organization's existing templates](./11-clone-a-template).

:::

## Prepare to create a template

Following are some things to know about configuring a template.

- There is no limit for the number of templates you can create.

- Templates are shared at the organizational level, and all approved users can access all templates.

## Create a template

1. Click the menu icon (<FAIcon icon="grip" />) at top left.

2. In the search field, enter **Roster Template Setup**. When it shows in the list of results, select **Roster Template Setup**.

3. Next to **Clearpath Roster Templates**, click **Add New Roster Template**.

4. Enter a name for the template. Users will see this name when generating a roster. As a best practice, enter the name of the carrier the template is for.

5. Enter a description for the template.
