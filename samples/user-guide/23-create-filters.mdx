# Create filters

First, [configure the template](./18-configure-a-template-s-layout).

Create filters to include or exclude groups of producers in a roster. Filters are optional.

1.  On the **Roster Templates** page, click the **Filters** tab in the center panel.

2.  Initiate a filter on any on the following objects:

    1.  The **Roster Filters** field contains the roster object. Click the filter icon (<FAIcon icon="filter" />) next to the roster object.

    2.  If you [chose the **Related Record** relationship type](./13-choose-a-relationship-type) and [used sub-objects](./18-configure-a-template-s-layout) when creating the template, click the filter icon (<FAIcon icon="filter" />) next to a related record object in the **Related Records Filters** list.

    3.  If you [chose the **Junction Object** relationship type](./13-choose-a-relationship-type) and [used sub-objects](./18-configure-a-template-s-layout) when creating the template, click the filter icon (<FAIcon icon="filter" />) next to a sub-object in the **Junction Filters** list.

3.  Filter records using conditions. Select a condition in the **Select Condition** dropdown field.

4.  Select a field, operator, and value to create a condition.

5.  Click **Add Condition** to set more conditions. Click the trash icon (<FAIcon icon="trash" />) next to a condition's row to remove conditions.

6.  Click **Save**.

For example, the following filter condition includes only active producers in the roster.

| Field                  | Contents                     |
|------------------------|------------------------------|
| Condition Requirements | All Conditions Are Met (AND) |
| Field                  | Appointment Status           |
| Operator               | Equals                       |
| Value                  | Active                       |

Next, [activate the template](./24-activate-or-deactivate-a-template).
