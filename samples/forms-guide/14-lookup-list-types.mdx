# Lookup list types

A lookup list associates a standard set of values with a field, so entries stay consistent across records and apps.

<LookupListTypeGrid />

Lookup lists are global or app-specific, and query-based, table-based, or a quick list. You pick a scope and a type when you [create one](./16-create-a-query-based-lookup-list).
