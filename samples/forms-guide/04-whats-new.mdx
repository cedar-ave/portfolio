# What's new in Clearpath Collect

## Modernized interface

Collect was rebuilt on a modern web framework with a REST web-service layer underneath.

## Support for tablets

Users can now enter data in a Collect app from a tablet, not just a desktop browser.

## Tighter integration with Clearpath

Collect apps write directly to individual tables in your Clearpath warehouse, each with its own defined column types. Data no longer lands in a single untyped table that has to be exported before it's usable in reporting.

## JSON REST API

A JSON REST API gives programmatic access to create, read, and write Collect apps from any client. API documentation is embedded directly inside Collect, in an interactive framework that lets you try methods, parameters, and models from the source.

## Lookup lists for mapping standard data sets

Earlier versions split standard lists and dropdown lists into two separate features. Collect streamlines both into a single feature: lookup lists. Whether you're mapping a global list to multiple apps or just one list to a single app, it's a more consistent experience with fewer dialogs.

## Access management with directory groups

Admins can manage access to Collect apps with your organization's directory groups instead of managing security user by user.

## Migration tool

A console-based migration tool moves existing apps from the previous version of Collect into the current platform. See the Clearpath Collect Migration Tool Guide.
