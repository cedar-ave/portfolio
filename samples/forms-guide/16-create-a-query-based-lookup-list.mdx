# Create a query-based lookup list

**Permissions:** You must be a Collect Administrator, or hold the Create Lookup List permission.

1. On the Collect home page, click **Lookup Lists** in the menu bar.
2. Click **New Lookup List**.

Query-based is the default type. The **View Name** and **Query** fields are required — they're outlined in red with an alert tooltip until filled in.

3. Assign a view name. It must start with a letter, be alphanumeric, and contain no spaces. The only special character allowed is `_`.
4. Under **Lookup List Type**, confirm **Query-Based** is selected.

You can switch between Query-Based and Table-Based freely until you save — after that, the type is locked. If you've already started adding a field (table-based) or a query (query-based), switching types shows a changes-detected modal confirming you want to discard that work. The modal won't appear if you've only entered a view name or made no other changes. Discarding keeps the view name but clears everything else.

5. Enter a query.

<LookupListCreateForm type="Query-Based" />

Enter a single `SELECT` statement — update, insert, and delete queries are rejected with an error. The query is saved as a view, and it can only run against your Clearpath warehouse or metadata database.

If you try to navigate away with unsaved changes, a changes-detected modal confirms whether to discard them. Choosing **Yes** returns to the lookup-list view without saving; choosing **No** dismisses the modal and keeps you on the page.

6. Click **Save**. Any invalid or missing required fields are flagged and block saving until corrected.
