# Lookup list permissions

## Global lookup lists

| Action | Permission required |
|---|---|
| Create | Be a Collect Administrator, or hold the global Create Lookup List permission |
| View or use | Be a Collect Administrator, or hold the global Manage Lookup Lists permission |

## Application-level lookup lists

| Action | Permission required |
|---|---|
| Create | Be an Application Administrator, or hold the app-level Create Lookup List permission |
| View or use | Be an Application Administrator, or hold the app-level Manage Lookup Lists permission |
