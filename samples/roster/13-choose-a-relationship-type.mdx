# Choose a relationship type

First, [choose objects to store carriers and producers](./12-choose-objects-to-store-carriers-and-producers).

Choose between two relationship types:

- [Related record](./14-about-a-related-record)

- [Junction object](./15-about-a-junction-object)

Fill out the following field:

| Field                    | What to select                                                                         |
| ------------------------ | -------------------------------------------------------------------------------------- |
| Select Relationship Type | Select a relationship type to determine how carrier and producer objects are associated. |

Next, see one of the following:

- [Configure a related record relationship type](./16-configure-a-related-record-relationship-type)

- [Configure a junction object relationship type](./17-configure-a-junction-object-relationship-type)
