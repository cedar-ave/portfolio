# Focus Mart Designer

<Subtitle>A simple, visual user experience for creating and deploying custom data marts in the data warehouse.</Subtitle>

In the past, pulling information out of various source systems to perform calculations was a time-consuming, manual task that required specialized IT knowledge. It could take months to build an individual Focus Mart in a data warehouse and start getting answers to questions.

Focus Mart Designer simplifies that process. By relying on the metadata captured by Clearpath's metadata-driven ETL engine when a source system is loaded into the data warehouse, Focus Mart Designer pulls relevant data into a Focus Mart and filters out anything not needed. Analysts then run calculations on that data and create visualizations that reflect the results.

## Definition management

Focus Mart Designer allows users to:

- Create or modify Focus Marts
- Manage the lifecycle of Focus Marts
- Create Focus Mart definitions
- Search the metadata of existing Focus Marts

## Collaborative value

Focus Mart Designer provides a simple, visual user experience for creating and deploying Focus Marts. Clinicians and data architects actively work together to build a Focus Mart, which can often be built in just one day, and the organization starts realizing value immediately.
