# Advanced Analytics

<Subtitle>Less time managing data, more time visualizing it.</Subtitle>

The key to outcomes-driven analytic insights is extracting the data needed — and only the data needed — to:

- Build custom Focus Marts that allow users to make calculations
- Feed business intelligence tools to create visualizations of trends

Clearpath's adaptive-binding architecture helps healthcare organizations rapidly achieve both, for a broad scope of clinical and operational processes.

## Rapid construction

The Focus Mart Designer tool bypasses the laborious process of retrieving data from individual source systems to build custom Focus Marts.

Once the metadata-driven ETL engine integrates source system data into the data warehouse, data architects create Focus Marts that measure specific cost and quality metrics.

## Data visualization

After that late-bound data is fed into analytics applications targeting specific interventions, it isn't long before users delve into insights, create and analyze visualizations, and kick off improvement initiatives.

## Instant deployment

The Clearpath architecture also includes out-of-the-box data applications, ready for deployment to hundreds of users shortly after key data sources are loaded.
