# Samples of guides

- [Norway Data API Guides](/samples/norway-data-api-guides/show-a-random-fact) - developer tutorials for my live [Norway Data API](/api-reference), with JavaScript and Python code you can run. Unlike the other samples, these aren't genericized.
- [Clearpath Roster User Guide](/samples/clearpath-roster-guide/get-started) - a user guide for generating and sharing rosters of appointed producers with insurance carriers.
- [Clearpath Collect User Guide](/samples/clearpath-collect-guide/01-overview) - a user guide for building custom data-entry apps that capture claims and underwriting data an insurer's core systems don't.
- [Docs-as-Code Contributor Guide](/samples/contributor-guide/02-prerequisites) - a contributor guide for a docs-as-code site: onboarding, writing templates, build troubleshooting, and platform admin reference.
- [Release Notes Automation Guide](/samples/release-notes-automation-guide/26-types-of-publications) - an engineering-driven workflow that turns Azure DevOps work items into published release notes, known issues reports, critical and high bugs reports, and change announcements.
