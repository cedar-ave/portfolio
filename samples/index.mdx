# Samples

Sample documentation, written to demonstrate structure and style rather than a real product.

- [User guide](/samples/user-guide/01-overview) - a user guide for generating and sharing rosters of appointed producers with insurance carriers.
- [Clearpath Collect user guide](/samples/forms-guide/01-overview) - a user guide for building custom data-entry apps that capture claims and underwriting data an insurer's core systems don't.
- [Technical marketing](/samples/technical-marketing/clearpath-analytics-platform) - product marketing pages for a healthcare data warehousing platform, from its adaptive-binding architecture down to individual applications.
