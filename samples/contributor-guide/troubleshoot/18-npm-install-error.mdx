# npm install error

## Symptom

The build fails with the following error:

```plaintext
SyntaxError: Unexpected token in JSON at position 0
```

## Solution

In **gulpfile.ts**, change:

```typescript
var docfxSettings = JSON.parse(fs.readFileSync('./docfx.json'));
```

to

```typescript
import * as docfxSettings from './docfx.json';
```

Next, add **tsconfig.json** at root:

```json
{
"compilerOptions": {
    "module": "commonjs",
    "target": "esnext",
    "resolveJsonModule": true
    }
}
```
