# 'Microsoft.NET.Sdk' specified could not be found

## Symptom

A `'Microsoft.NET.Sdk' specified could not be found` error is shown when you build the site.

## Solution

1. Go to Visual Studio Installer.
2. Click **Visual Studio Build Tools 2019** > **Modify** > **Individual Components** tab.
3. Check **.NET SDK** > **Modify**.
4. Restart.
