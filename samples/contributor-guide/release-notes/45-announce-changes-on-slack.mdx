# Announce changes on Slack

## Vertex team Slack bot

Post a message from the **Vertex Team** Slack bot in the **#general** Slack channel.

## Use cases

- When a new release is announced
- Congratulations to another team
- Links for team members (like demo environments)

## Setup

A Slack incoming webhook posts to **#general**:

```plaintext
<slack-incoming-webhook-url>
```

## Usage

Use Postman or something similar to `POST` JSON to the Slack incoming webhook.

### Example of a release announcement

See the release-notes repo's **announcement** directory for JSON examples of past announcements.

To include a channel mention in the payload, use the ID at the end of the URL when in the channel in the browser. For example, **#engineering-general** is `<#CHANNEL-ID>`.

To change the avatar emoji, the name the message is posted from, or the Slack channel the message is posted to, go to Slack > Your name at top left > **Administration** > **Manage Apps** > **Custom Integrations** > **Incoming WebHooks** > **Posts to #general as Vertex Team**.
