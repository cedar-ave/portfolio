## Quick reference

### Formatting

| Guideline | Wrong | Right |
| --- | --- | --- |
| Bold names of elements visible on a screen, like interface elements (headings, buttons, links), table components, errors, etc. | Click *Save*. | Click **Save**. |
| Use plain text for nouns. | Open the **SAM**... | Open the SAM... |
| Italicize terms when defined. | In this guide, **Securable type** refers to... | In this guide, *Securable type* refers to... |
| Use the code character style (backticks in Markdown) to display what a user types in or API methods. | <ul><li>Press **Enter**.</li><li>Send a GET request.</li></ul> | <ul><li>Press `Enter`.</li><li>Send a `GET` request.</li></ul> |

### Style

#### Word choice

| Guideline | Wrong | Right |
| --- | --- | --- |
| If it can be said in fewer words, take the opportunity. | ...before taking the timeout action... | ...before timing out... |
| | ...completed its loading process... | ...finished loading... |
| | ...in situations where... | ...when... |
| | ...warrant failure of... | ...fail... |

#### Usage

| Guideline | Wrong | Right |
| --- | --- | --- |
| Use active voice. | ...when source marts are loaded... | ...when source marts load... |
| Use present tense. | <ul><li>...the application will save the files...</li><li>...the application should save the files...</li><li>...the application saved the files...</li></ul> | ...the application saves the files... |
| Use second person. | ...the files need to be re-uploaded... | ...re-upload the files... |
| | ...allows for the selection of... | ...lets you select... |
| Standardize singular vs. plural (singular is preferred). | To import files, load the file from the database. | Load a file to import it from the database. |
| Lowercase improper nouns. | Source Mart | source mart |
| | ...save the Record to the Database... | ...save the record to the database... |
| Click, don't select, buttons. | Select the **OK** button. | Click **OK**. |

#### Headings

| Guideline | Wrong | Right |
| --- | --- | --- |
| Make article titles and headings imperative; avoid gerunds (-ing). | Designing a source mart | Design a source mart |
| Make headings sentence case. | Build an Application | Build an application |
| Capitalize only the first word of a heading unless it has proper nouns. | Create an IDEA Application | Create an IDEA application |

#### Bullets and numbers

- Use bullets, not numbers. Often authors exploit numbered lists by creating deeply nested outlines.
- Punctuation:
  - If the list items are complete sentences, end them with periods.
  - If the list items are not complete sentences, don't add periods.
- Break up long bulleted lists into multiple sections with headings.

#### Screenshots

- Put the screenshot before the step.
