## Checking local updates into Azure DevOps

1. After finalizing and saving your content changes in Visual Studio (VS) Code, click the version control icon.
2. Click the plus icon above your list of changes. This will stage all your changes and prepare them to be committed to your local repository branch.
3. Click in the commit message field.
4. Type a brief, clear message describing your changes (something that will help you remember what you did when you're reviewing the revision history).
5. Click the check icon to commit your changes to your local repository branch.
6. Look to see which branch you're working in (lower left corner of the screen). If it's the main branch, you'll want to create a new branch to publish your changes on Azure DevOps. Click on the branch name.
7. Click in the input field in the top middle of the screen and type your branch name (e.g., `user/your.name/short-branch-description`).
8. Click + Create new branch.
9. Click Publish Branch to publish your new branch with your content changes to Azure DevOps.

## Create a pull request

1. Navigate to the site repository in Azure DevOps. You should see a message mid-screen showing the branch you just published.
1. Click Create a pull request.
2. Name the pull request and enter a description if changes were complex (for brief, simple changes, descriptions aren't needed). Make sure you are merging into the right branch (this will usually be "main" or "master").
3. Click Create. Azure DevOps performs a test merge to see if your changes conflict with changes in the destination branch.
4.  If you have merge conflicts, click Conflicts and review the changes that are conflicting.
5. Review the changes that are conflicting. To resolve them, click the dropdown next to Submit Merge.
6. Choose which changes to keep.
7. Click OK.
8. After resolving any conflicts, click Overview to go back to the main screen.
9. If your changes are complex, add reviewers and wait for them to approve before completing your pull request. If your changes are simple, you can approve them. If appropriate for your situation, click Approve.
10. After you have necessary approvals, click Complete.
11. In the slide-out pane, click Complete merge. This merges your changes into the destination branch you selected and kicks off the build pipeline.

## Create a pull request

1. Navigate to the project repository in Azure DevOps.
1. Click **Create a pull request**.
1. At the top, verify that the branch you are pulling updates from is listed, and either `main` or `master` is listed as the branch you're pulling the content into.
