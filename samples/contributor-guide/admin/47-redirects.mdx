# Redirects

## Option 1: Add redirect in article

```yaml
---
uid: page.md
title: Page
redirect_url: [new URL]
---
```

See URL Redirects in the DocFx documentation.

## Option 2: Add redirect in Redirect.yml

Add redirects in **Redirect.yml** (site-theme repo > **src/homepage/Redirect.yml**).

The source file for the page being redirected does not have to remain in the blob.

It also works for pictures and videos. They reload in the page.

A future enhancement might be to support Regex and patterns.
