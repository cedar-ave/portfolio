# Table of contents styles

| Class | Details |
| --- | --- |
| toc-heading | Not a link; hover color does not change |
| toc-heading-active | Is a link; hover color changes |
| line-above | |
| line-below | |
| margin-below-toc | Adds a margin between the table of contents and bottom of the page to improve visibility of final item |

For example:

```yaml
- name: Name
  class: toc-heading line-above
```
