# Outline - Concept

Copy and paste into a new Markdown file and fill out.

<Panel>

```md
---
uid: filename.md
title: Title
---

# Title

Provide background information a user needs to know about a product, process,
or system to successfully complete tasks. Examples are helpful. As much as
possible, avoid documenting concepts a user can learn easily by searching the
web.
```
